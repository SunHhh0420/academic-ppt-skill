## 1. 规划自检（大纲阶段）

- [ ] 已明确场景、总时长、页数上限与听众
- [ ] 一句话研究问题/核心主张已写出，第 2–3 页内可见
- [ ] 选定一条叙事脊柱（SCR / 漏斗 / 结论先行）并贯穿全篇
- [ ] 每条主线主张都映射到具体证据页；无主张支撑的材料已移入附录
- [ ] 大纲通过幽灵稿测试：标题连读讲得出完整论证
- [ ] 大纲通过衔接测试：每页是上一页的自然推论，无可随意挪动的多余页
- [ ] 已提前标出时间紧时可砍的页面

## 2. 论证与标题

- [ ] 每张内容页标题是完整结论句，而非名词标签
- [ ] 标题一到两行；同类页面标题位置/字号/对齐一致
- [ ] 每页只承担一个论证角色；做两件事的页已拆分
- [ ] 研究问题独立成页，未埋在动机页
- [ ] 结论页是主线最后一页，问答阶段留屏；未以"谢谢聆听"或空白页收尾

## 3. 证据与数据

- [ ] 结果页一页一个证据；两个图若讲同一对比则合并，否则分两页
- [ ] 每条证据直接支撑本页标题（互测：盖标题证据仍成立则证据多余；盖证据结论不明则标注不足）
- [ ] 关键发现在图/表上直接标注（箭头、高亮、文字标注），不让听众自行找
- [ ] 图表脱离讲稿也能读懂（自给自足测试）
- [ ] 定量对比含基线、数据集、指标与本方法数值；最优值突出标注
- [ ] 消融每次只变动一个变量；失败案例与局限部分呼应
- [ ] 数字与实验记录一致；缺失项如实标注，无编造数据

## 4. 引用与学术诚信

- [ ] 所有借用的图、数据、主张在页内标注来源
- [ ] 有 References 页，文献格式全篇统一
- [ ] 他方图片注明出处与图号；未使用无来源图片
- [ ] 主张强度与证据等级匹配，无过度断言

## 5. 文本与视觉

- [ ] 每页正文要点 3–5 条、约 40 词以内；超出则拆页或移入附录
- [ ] 正文字号达到投影可读下限；标题/正文/图注层级分明
- [ ] 全篇一套字体；配色仅主色 + 中性色，无渐变、阴影、彩虹配色
- [ ] 元素对齐统一网格，留白充足；同类页面版式一致
- [ ] 不只靠颜色区分信息；文字与背景对比充足
- [ ] 无装饰性图标、贴纸、无关配图；无 AI 味色条/边框/标题下划线
- [ ] 图表内文字在投影尺寸下可辨认；图注、坐标轴标签齐全

## 6. 时间与讲稿

- [ ] 页数符合时长预算；演练可提前 1–2 分钟收尾
- [ ] 每页备注有 3–5 句可直接照读的讲稿，未照念 bullet
- [ ] 方法与结果讲解时间占一半以上
- [ ] 已准备 5–10 个预判问答，并对应预置附录页
- [ ] 不确定的问题标注为待补充，未编造结论
