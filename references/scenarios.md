## 1. 学位 / 开题 / 毕业答辩

**听众**：答辩委员会、导师组；关注选题价值、工作量、方法严谨性与结论可靠性。
**时长参考**：毕业答辩 15–20 分钟、20–28 页；开题 10–15 分钟、15–20 页。

### 推荐章节与页数配比

| 章节 | 页数占比 | 要点 |
| --- | --- | --- |
| 封面 | 1 | 题目、姓名、导师、专业、日期；题目即研究问题 |
| 研究背景与动机 | 1–2 | 行业/领域现状 → 现存问题 → 本课题要解决什么；压缩铺垫，不展开综述 |
| 相关工作 | 1 | 只列与本方法直接对比的方向，点出他人不足与本工作切入点 |
| 研究目标与贡献 | 1 | 一句话总贡献 + 2–3 条可核验的具体贡献 |
| **方法 / 框架（视觉中心）** | 5–8 | 总体框架图前置；再分模块讲解输入、核心模型/算法、损失与推理流程 |
| 实验与结果 | 4–6 | 数据集与评价指标 → 主对比表/图 → 定性可视化 → 消融实验 |
| 结论与展望 | 1–2 | 总结贡献、列出局限、说明后续方向 |
| 致谢 / 问答页 | 1 | 致谢导师与合作者；末页留联系方式或"谢谢聆听" |

### 取舍要点

- 方法与实验合计占版面与时间一半以上；背景、相关工作能一页放下就不用两页。
- 开题阶段可弱化已完成结果、强化研究计划与预期指标；毕业答辩必须以定量结果支撑工作量。
- 涉及模型架构、公式、流程图时，图优先于大段公式；公式只保留核心一条，其余放备注。

## 2. 会议 / 期刊口头报告

**听众**：领域同行与审稿人；关注创新点、与 SOTA 的差异和结果说服力。
**时长参考**：会议口头 10–15 分钟、12–18 页；海报宣讲式短讲 5 分钟、6–8 页。

### 推荐章节与页数配比

| 章节 | 页数占比 | 要点 |
| --- | --- | --- |
| 标题页 | 1 | 论文标题、作者、单位、会议名称 |
| 问题与动机 | 1 | 用一个具体场景或失败案例切入，引出待解问题 |
| 方法 | 3–5 | 一张总览图讲清思路；核心创新点逐条展开，配关键模块示意 |
| 实验结果 | 3–5 | 主表/主图放最显眼位置；挑 1–2 个最有说服力的对比与可视化深入讲 |
| 结论 | 1 | 一句话总结 + 局限；不展开未来工作 |

### 取舍要点

- 严格卡时长：每页约 45–60 秒；超时先砍相关工作与次要消融，保留主方法与主结果。
- 标题写结论式句子（如"在 X 基准上准确率提升 3.2 个点"），不写"实验结果"这类空标题。
- 与 SOTA 的对比必须列基线、指标和数据集；配图需能在投影上看清，小图放大或拆页。

## 3. 课题组会 / 周报汇报

**听众**：导师与同门；关注进展、遇到的问题与下一步计划。
**时长参考**：5–10 分钟、6–10 页。

### 推荐结构

1. **本周进展（1–3 页）**：做了什么、得到什么初步结果，配最小必要图表。
2. **问题与卡点（1–2 页）**：现象、已尝试的方案、未解决的原因；需要导师/同门协助的点单列。
3. **下周计划（1 页）**：可执行的任务清单与预期产出；给出时间节点。
4. **可选：相关阅读（0–1 页）**：本周读的论文要点与对自己课题的启发。

### 取舍要点

- 不追求完整叙事闭环，重点是让导师快速判断方向是否偏、卡点是否需要介入。
- 未完成的实验如实标注"进行中/待补"，不用占位图或编造数字。
- 页面信息密度可略高，但标题仍要写清结论或状态（"基线已复现，指标待对齐"）。

## 4. 学术海报转 PPT

**听众**：现场同行或二次汇报对象；从海报的分区信息重组为线性叙事。

### 重组步骤

1. **拆解海报模块**：标题、摘要、动机、方法、实验、结论、图表分别抽取为素材。
2. **重排叙事线**：按"问题 → 方法 → 证据 → 结论"重排；海报上并列的模块在 PPT 里按论证顺序分页。
3. **保留视觉中心**：海报中最大的方法/框架图对应 PPT 的方法主图；定量表格与关键曲线保留，压缩大段文字。
4. **补讲稿**：海报靠读者自行阅读，PPT 需为每页补口播备注（见 [speaker-notes.md](speaker-notes.md)）。

### 取舍要点

- 海报上的小字注释、图例脚注，转 PPT 后精简为页内要点或备注，不直接堆上幻灯片。
- 一张信息过密的海报页可拆成 2–3 张幻灯片；同一张图不在多页重复出现。

## 通用章节要素对照

| 论证角色 | 必答问题 | 常见素材 |
| --- | --- | --- |
| 背景 | 领域在做什么，为什么重要 | 场景图、趋势、数据 |
| 动机 | 现有方法哪里不够，本工作针对什么缺口 | 失败案例、对比局限 |
| 方法 | 提出什么思路，怎么实现 | 框架图、模块示意、核心公式 |
| 实验 | 是否验证了主张，相比基线好多少 | 对比表、曲线图、可视化、消融 |
| 结论 | 最终贡献与边界 | 总结要点、局限、展望 |
