## 1. 完整 Deck 架构（按顺序）

完整学术汇报应包含以下页面；短讲可合并背景与问题，但研究问题页与结论页不能省。

| 顺序 | 页面 | 职责与要点 |
| --- | --- | --- |
| 1 | 标题页 | 题目（尽量写成陈述句或研究问句）、作者、导师/单位、场合、日期；校徽/院徽仅作最小身份识别 |
| 2–3 | 背景 / 动机 | 为什么重要；连接到真实缺口、未解问题或争议。对应 SCR 的情境与冲突，压缩铺垫 |
| 3 | 研究问题 / 假设 | **独立成页**，明确精确地写出问题或假设；这是后续评估的锚点 |
| 4 | 贡献概览（可选） | 一句话总贡献 + 2–3 条可核验的具体贡献 |
| 5–… | 方法 | 只讲评估结论所需的设计；不影响可解释性的流程细节移入附录。框架图前置 |
| … | 结果（一页一发现） | 每页一个证据，标题陈述发现，关键结果在图/表上直接标注 |
| … | 讨论 / 意义 | 解释结果，回扣开头研究问题；正面回应主要局限 |
| 倒数第二 | 结论页 | 2–4 条要点重述核心结论；**问答阶段此页留在屏幕上** |
| 末前 | 联系方式 | 邮箱、单位主页/预印本链接或二维码；可与结论页合并 |
| 附录 | 补充材料 | 预置问答页、稳健性/消融补充、额外图表、详细推导；单独标注 |

**收尾规则**：主线最后一页是结论页，不要以"谢谢聆听"、空白页或装饰页结束。问答邀请用"是否有问题或建议"，比单纯"还有问题吗"更易引出实质讨论。

## 2. 附录组织

- **预置问答页**：为预判的每个高频问题准备一页（见 [speaker-notes.md](speaker-notes.md)）。
- **稳健性与补充实验**：敏感性分析、额外数据集、完整消融、失败案例细节。
- **方法细节**：超参、训练配置、推导证明、未进主线的基线。
- 每张附录页仍用结论式标题；页首用小字标注"附录 A：稳健性检查"等，与主线视觉区分。
- 主线没讨论到的图不要留在主线；放附录备查。

## 3. 引用与学术诚信

- **页内引用**：任何非本人原创的主张、图、数据集，在出现该内容的页面底部以较小、弱化字号标注；沿用本领域惯例格式——社科/理工用（作者, 年份），人文用脚注或上标编号，全篇统一。
- **口述出处**：引用他人结论时先口头交代来源，不要静默甩出一个括号引用。
- **他方图片**：图下直接标注出处（如"Source: Jones et al., 2021, Fig. 3"），完整文献放在 References 页；会议演示通常适用合理使用，存疑时确认版权。
- **References 页**：附录前最后一张主线页，列出 deck 中引用的全部完整文献，格式统一。
- **不编造**：缺失的数据、引用、案例明确标为占位/待补；不用占位图冒充真实结果。

## 4. 时间预算与砍页预案

### 页数预算（经验值：约一页一分钟）

| 时长 | 主线内容页数（不含标题/参考文献） |
| --- | --- |
| 10 分钟 | 8–10 页 |
| 15 分钟 | 12–14 页 |
| 20 分钟 | 15–18 页 |
| 45 分钟研讨 | 30–40 页，每页留讨论余量 |

### 节奏规则
- 方法与结果合计占一半以上时间；背景、相关工作最先压缩。
- 演练计时，目标在限时内**提前 1–2 分钟**收尾——现场紧张与互动总会加时；超时在学术会议上是明显的职业失误。
- **提前标记可砍页**：大纲阶段就标出时间紧时可跳过的页面（角落小标记）；优先保住研究问题、关键结果与结论，方法与背景最先让位。

## 5. 无障碍与国际化

- 正文不小于投影可读下限（见 [design.md](design.md) 字号表）；标题与正文高对比。
- 不只靠颜色传达信息：辅以标签、线型或形状，避免色弱听众无法区分。
- 面向国际听众：避免俚语、文化梗；缩写首现即展开定义；句式简单直接。
- 若 deck 会作为 PDF 传阅，为图片补充替代说明文字。
