## 1. 版面层级与权重

按论证角色分配视觉权重，方法为视觉中心：

- **方法页（最高权重）**：占据最大面积，主图/框架图居中或居左上重心；标题与说明文字围绕主图排布。
- **结果页（次高权重）**：主表/主图落在视觉重心，对比结论用简短标注突出；图表占页面三分之二以上。
- **背景/动机页（低权重）**：压缩为少量要点或一张场景图，不做整页长文。
- **过渡页（最低权重）**：仅章节名与一句引导，不放正文。

单页视觉层级自上而下：页面标题（结论句）→ 主图/主表 → 要点标注 → 脚注/来源。读者视线先落到主视觉，再读标题要点。

## 2. 网格、对齐与留白

- 使用统一网格：左右边距一致，正文栏宽固定；多列内容按列基线对齐。
- 一页内元素对齐到同一条水平线或竖直线，不随意悬浮。
- 留白优先于塞满：要点不超过 5 条，每条不超过两行；删不掉的内容拆页或移入备注。
- 同类型页面（如多个结果页）保持相同标题位置、图表位置与字号，形成节奏。
- 页码、单位、数据来源放在页脚同一位置。

## 3. 配色

- **主色 1 个**：用于标题强调、主线条、关键数据高亮；可取自所在领域惯例或机构色。
- **中性色**：正文深灰/黑，背景白或极浅灰，辅助分隔线浅灰。
- 对比组用固定语义色：本方法一种色，对比基线统一用灰色系；多组曲线颜色在图例中区分，不随意换色。
- 避免大面积高饱和底色、渐变填充、阴影浮雕；彩色仅用于强调，不铺满整页。
- 保证投影可读：正文与背景对比度充足，浅灰底上不用浅灰字。

## 4. 字体与字号

- 全篇字体统一：中文一种无衬线字体（如思源黑体/微软雅黑），西文与数字一种配套无衬线字体；不混用多套字体。
- 字号层级参考（16:9 页面）：

| 元素 | 字号范围 | 说明 |
| --- | --- | --- |
| 页面标题 | 28–36 pt | 结论句，加粗 |
| 副标题/小节标题 | 20–24 pt | |
| 正文要点 | 16–20 pt | 投影可读为底线，不小于 16 pt |
| 图表内文字 | 14–16 pt | 坐标轴、图例、表内文字 |
| 脚注/来源 | 10–12 pt | 数据出处、补充说明 |

- 数字与单位同字号；英文缩写、模型名（如 DINOv2、SMPLX）保持原名大小写，不强行翻译。
- 行距宽松，要点之间留足间距；不使用花哨艺术字。

## 5. 各类页面版式

### 封面页

- 顶部或中部放论文/课题题目（结论式题目优先）；下方依次为姓名、导师、单位/专业、日期。
- 背景干净，可放一张与主题相关的低调示意图；不堆装饰图标。

### 目录 / 概览页

- 列出本次汇报的章节顺序；当前章节可高亮，其余置灰。
- 短报告（5–10 分钟）可省略目录页。

### 章节过渡页

- 仅章节序号 + 章节名 + 一句本节要回答的问题；不重复上一章结论。

### 内容页

- 标题在顶部写结论句；主视觉居中；要点用短 bullet，配合箭头/编号表达逻辑顺序。
- 左右分栏时，左图右文或左文右图保持全篇一致。

### 结果页

- 主表/主图优先；关键数字或最优结果加粗/主色标注；图表标题说明结论而非仅写"结果"。
- 详细误差棒、显著性标记、数据集缩写在图例或脚注解释。

### 结束页

- "谢谢聆听 / 敬请批评指正" + 联系方式；可附一句话总结贡献。

## 6. 复核清单

- [ ] 每页标题是否为结论句，而非名词标签
- [ ] 方法页是否为全片最大视觉块，背景页是否已压缩
- [ ] 配色是否仅 1 个主色 + 中性色，无多余渐变阴影
- [ ] 字体是否统一，正文字号是否达到投影可读底线
- [ ] 所有元素是否对齐网格，留白是否充足
- [ ] 同类页面版式是否一致
- [ ] 图表内文字在投影尺寸下是否可辨认
