## 1. 讲稿原则

- 讲稿写在每页备注中，口播与幻灯片互补：页面给要点与图，讲稿补充推理过程、过渡衔接与取舍理由，不照念 bullet。
- 用口语化短句；专业术语首次出现时一句话解释。
- 每页讲稿控制在对应时长内，预留翻页与停顿时间。
- 数字、指标与页面一致；讲稿中可补充页面放不下的细节与引用出处。

## 2. 逐页讲稿模板

为每页备注按以下结构组织（按页面角色取舍）：

**背景/动机页**
- 一句话场景或问题：现在领域面临什么情况。
- 缺口：现有做法哪里不足。
- 过渡：所以本工作聚焦什么问题。

**方法页**
- 思路总览：用一句话说明核心做法。
- 模块讲解：按流程图顺序，逐个说明输入、作用、输出。
- 创新点：本模块与已有做法的关键差异。

**结果页**
- 先报结论：在什么数据集、什么指标上，相比基线提升多少。
- 再读图/表：指出关键曲线、最优项与对比对象。
- 补充：现象背后的原因，或仍存在的不足。

**结论页**
- 回收开头问题：本工作如何回答了最初的问题。
- 贡献与局限：明确列出做到了什么、边界在哪。

## 3. 时间分配

- 按总时长反推每页秒数：方法与结果页占一半以上时间，背景与相关工作快速带过。
- 预留缓冲：总讲稿时长控制在限时的 85–90%，留出提问、翻页与现场停顿。
- 提前演练计时；超时优先删减细节展开与次要消融，不压缩主结果讲解。

参考配比（以 15 分钟答辩为例）：背景与动机 2 分钟 → 方法 6 分钟 → 实验 5 分钟 → 结论与展望 2 分钟。

## 4. 开场与收尾

**开场（30 秒内）**
- 报题目与姓名；一句话说明研究问题与核心贡献，让听众先建立整体预期。

**收尾**
- 一句话总结贡献；致谢导师、合作者与资助方；以"敬请批评指正"结束。
- 末页留存联系方式与关键结论，便于提问时回看。

## 5. 问答预判与应答框架

### 高频问题类型

| 类型 | 典型问题 | 应答要点 |
| --- | --- | --- |
| 动机与价值 | 这个问题为什么重要？与已有工作区别是什么？ | 回到缺口与切入点；明确与最接近工作的差异 |
| 方法合理性 | 为什么用这个模块/损失/结构，换另一种行不行？ | 讲设计依据与备选取舍；未验证的方向如实说明 |
| 实验严谨性 | 基线是否公平？指标是否充分？是否做了显著性检验？ | 说明数据划分、复现口径、误差来源；承认不足 |
| 结果边界 | 在什么场景失效？泛化性如何？ | 结合失败案例与局限说明；给出后续验证计划 |
| 工作量与规划 | 各部分贡献占比？下一步计划？ | 清晰划分个人工作；开题/组会类讲清时间节点 |

### 应答框架

1. **先直接回答**：用一句话给出明确结论，不绕铺垫。
2. **给证据**：引用对应图表、数字或实验设置支撑。
3. **承认边界**：不确定或未验证的部分如实说明，不临场编造；可记录问题会后补充。
4. **必要时引用备份页**：把补充消融、额外结果放在备份幻灯片，问答时调出。

### 准备动作

- 列出 5–10 个最可能被问到的问题，逐条写要点答案。
- 检查所有数字可在备份材料中回溯到原始实验记录。
- 对容易被追问的方法细节、超参选择准备一句简短解释。

## 6. 复核清单

- [ ] 每页备注是否与幻灯片结论一致，未照念 bullet
- [ ] 讲稿总时长是否控制在限时的 85–90%
- [ ] 方法与结果讲解时间是否占一半以上
- [ ] 开场是否一句话讲清问题与贡献
- [ ] 是否准备 5–10 个预判问题及要点答案
- [ ] 不确定的问题是否明确标注为待补充，而非编造结论
