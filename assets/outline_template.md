# 学术汇报大纲模板

> 复制本文件填写。每页只承担一个论证角色；标题写成结论句；证据直接支撑标题。
> 也可用脚本按场景自动生成骨架：`python3 scripts/plan_deck.py --scene <场景> --minutes <分钟> --out outline.md`

## 元信息

- 题目：〔陈述式题目或研究问句〕
- 场景：〔答辩 / 会议报告 / 组会周报 / 海报转 PPT〕
- 总时长：〔  〕分钟　页数预算：约〔  〕页
- 听众：〔评委 / 同行 / 导师同门〕
- 核心主张（一句话）：〔  〕
- 关键证据（2–3 条）：〔  〕

## 主线页面

### P01 · 封面
- 结论式标题：〔题目〕
- 要点：作者、导师、单位/专业、场合、日期
- 证据/图表：〔校徽/院徽仅作最小识别〕
- 讲稿备注：〔3–5 句〕

### P02 · 背景与动机
- 结论式标题：〔  〕
- 要点：领域现状 → 现存缺口
- 证据/图表：〔场景图 / 趋势 / 失败案例，标注来源〕
- 讲稿备注：〔  〕

### P03 · 研究问题
- 结论式标题：〔本工作要回答的具体疑问〕
- 要点：问题陈述、假设、边界
- 证据/图表：〔问题陈述框〕
- 讲稿备注：〔  〕

### P04 · 方法 / 框架（视觉中心）
- 结论式标题：〔  〕
- 要点：总体思路、模块与数据流
- 证据/图表：〔框架图：模块 + 箭头 + 输入输出维度〕
- 讲稿备注：〔  〕

### P05 · 实验 · 主结果
- 结论式标题：〔在什么数据集、什么指标上，相比基线如何〕
- 要点：基线、指标、本方法数值、最优项
- 证据/图表：〔主对比表/图，关键发现标注在图上，注明来源〕
- 讲稿备注：〔  〕

### P06 · 实验 · 消融 / 定性
- 结论式标题：〔  〕
- 要点：逐组件增益 / 定性对比 / 失败案例
- 证据/图表：〔消融表 / 并排可视化〕
- 讲稿备注：〔  〕

### P07 · 讨论与局限
- 结论式标题：〔  〕
- 要点：结果解释、回扣研究问题、主要局限
- 证据/图表：〔  〕
- 讲稿备注：〔  〕

### P08 · 结论（问答留屏）
- 结论式标题：〔2–4 条核心结论，编号便于问答引用〕
- 要点：贡献、边界、后续方向
- 证据/图表：〔邮箱 / 预印本链接 / 二维码〕
- 讲稿备注：〔回收开头问题，邀请提问〕

## 附录（按需）

- 附录 A：预判问答页（问题 → 要点答案 → 对应证据）
- 附录 B：补充消融与稳健性检查
- 附录 C：额外数据集与完整对比表
- 附录 D：详细推导、超参与训练配置

## 填写后自检

- [ ] 标题连读能讲出完整论证（幽灵稿测试）
- [ ] 每页一个角色，证据撑得住标题
- [ ] 每页 bullet ≤ 5 条、正文 ≤ 约 40 词
- [ ] 借用的图与数据已标注来源，末尾有 References 页
- [ ] 已标出时间紧时可跳过的页面
